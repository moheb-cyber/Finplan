# FinPlan

A personal finance decision and planning platform focused on turning everyday financial data into clear, practical insights.

## Status

🚧 In active development.

## Goals

- Track income and expenses
- Organize financial transactions
- Summarize spending and financial activity
- Provide practical decision-support insights
- Build a clean, responsive and maintainable interface

## Tech Stack

- HTML / CSS / JavaScript
- Python
- FastAPI
- SQLite

## Project Structure

The project is organized into separate frontend and backend areas to keep the user interface, application logic and data layer easier to maintain.

## About

FinPlan is being built as a portfolio project with an emphasis on practical software engineering, useful financial workflows, clean UI and maintainable code.
